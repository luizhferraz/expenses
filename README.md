# Expenses

Um projeto simples para controle e visualização de despesas, criado como exercício de desenvolvimento front-end com React.

## 🧾 Sobre o Projeto

Permite o cadastro de despesas por valor, título e data, exibindo os lançamentos em uma lista filtrável por ano.  
Inclui gráficos de gastos mensais e experiência interativa.

## ✨ Funcionalidades

- Adicionar, listar e visualizar despesas.
- Filtro de despesas por ano.
- Visualização gráfica dos gastos.
- Interface responsiva.
- Componentização utilizando React.

## 🚀 Tecnologias Utilizadas

- **React**
- **JavaScript**
- **HTML**
- **CSS**

## ▶️ Como rodar o projeto

1. **Clone o repositório:**
    ```bash
    git clone https://github.com/luizhferraz/expenses.git
    ```
2. **Acesse a pasta do projeto:**
    ```bash
    cd expenses
    ```
3. **Instale as dependências:**
    ```bash
    npm install
    # ou
    yarn
    ```
4. **Execute o projeto:**
    ```bash
    npm start
    # ou
    yarn start
    ```

5. Abra o navegador em `http://localhost:3000` para visualizar a aplicação.
